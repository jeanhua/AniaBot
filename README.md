# 群聊部署分支

> 该分支为群聊部署的分支，特性会频繁变动，插件频繁修改，若想体验更多实时有趣的内容可关注本分支，若自行开发需要请切换main分支

### 新增插件

1. 抖音分享解析插件：分享抖音内容可解析视频直链
2. 二次元壁纸图片：可获取随机二次元壁纸
3. waifu.pics插件：获取分类随机二次元图和表情包
